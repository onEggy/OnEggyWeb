# Pricing & Engagement Models — OnEggy Technologies

OnEggy Technologies provides transparent pricing models tailored to high-growth startups and enterprises. We structure our contracts around clear, milestone-driven deliverables and predictable retainers.

## Engagement Tiers

### 1. Fixed-Scope Projects
- **Best for:** Infrastructure setup, cloud migrations, EKS orchestrations, and initial setups.
- **Pricing:** Milestone-based fixed pricing.
- **Structure:**
  - Milestone 1: VPC Network, Security Groups & IAM setup.
  - Milestone 2: AWS EKS / Kubernetes deployment, scaling configurations, and CI/CD pipelines.
  - Milestone 3: Testing, monitoring setups, and full documentation handover.

### 2. DevOps & Cloud Managed Retainers
- **Best for:** Continuous infrastructure monitoring, security patching, CI/CD pipeline management, and SRE support.
- **Pricing:** Predictable monthly subscription billed in advance.
- **Terms:** Requires at least 15 days written notice prior to the next billing cycle for modifications or cancellation.

### 3. Cloud Audit & Advisory Assessments
- **Best for:** Cloud cost audits, security reviews, and architecture roadmapping.
- **Pricing:** Fixed-fee advisory assessments.
- **Deliverables:** Exhaustive reports detailing risk parameters, security vulnerabilities, and cost optimization opportunities.
